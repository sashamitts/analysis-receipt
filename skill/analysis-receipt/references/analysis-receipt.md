## 1. Question

Owned by whoever set the question. Usually the researcher, sometimes with the decision maker.

### 1.1 Question and frame
_The question the analysis answers, word for word as it was given to every reader (people and models). The lens or framework used, if any. What the frame leaves out by design._

### 1.2 What it means for the decision
_The decision this analysis informs, and what the receipt changes about it. For example: ship as planned; ship with a stated limit; read more before deciding. If no decision rests on it, say so._

---

## 2. Readers

Owned by whoever ran the reading, by hand or with tools.

### 2.1 What was collected
_Everything in scope before any reading. Count and kind of material, for example 24 interviews, 1,800 open-ended responses, 40 session recordings. Where it came from and how it was selected._

### 2.2 What was read, and by which readers
_Each reader on its own row. A reader is anything that turned material into findings: a person, a model, a tool, a pipeline step._

| Reader | Person, model or tool (with version and date) | What it was given | What it actually read | Instructions or brief |
|---|---|---|---|---|
| _R1_ | | | | |

_"What it actually read" matters most. Note any sampling, truncation, chunking, retrieval, file caps or frequency cut-offs. If a tool cannot show what it read, write that here._

### 2.3 What was never read, and why
_Material in scope that no reader read: excluded files, failed transcriptions, sessions without consent to analyse, content in other languages. Give counts and reasons._

---

## 3. Leftovers

Owned by whoever checks what was set aside. This is the one line that produces new evidence rather than describing the work.

### 3.1 What counts as a leftover here
_Define the unit (a turn, a response, a note, a timestamped segment) and what makes it a leftover (for example, no finding quotes or cites it)._

### 3.2 What was sampled, and what it found
_Total leftovers. Sample size and how it was drawn (random, with the seed). Who read the sample. How many passages were labelled as a missed example of an existing finding, a new idea, or nothing relevant. The upper bound this gives (see tools/leftover_sample.py bound)._

| Total leftovers | Sampled | Seed | Read by | Existing finding | New idea | Nothing relevant | Upper bound on the share holding a new idea (95%) |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

### 3.3 Targeted searches for rare or misfitting material
_A random sample rarely catches what one or two people said. List any targeted searches (for example, leftovers ranked by how poorly the codes explain them, or a reader briefed to find people the question does not fit) and what they found. Write "None" if none were run._

### 3.4 What was not checked
_Named plainly. For example: the 950 interviews not drawn; one reference reader and no second coder; non-English responses._
